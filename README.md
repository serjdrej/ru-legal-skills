# ru-legal-skills

Плагин-маркетплейс Claude Code для навыков, связанных с российским правом и
российскими стандартами (ГОСТ). Собран основателем, который сам себе и юрист,
и инженер: каждый навык покрывает область, где ему приходится действовать
самостоятельно, без штатного специалиста.

## Установка

```
/plugin marketplace add serjdrej/ru-legal-skills
```

Затем для каждого нужного навыка:

```
/plugin install gost-ed-mashiny@ru-legal-skills
/plugin install legal-ru@ru-legal-skills
/plugin install patent-ru@ru-legal-skills
```

## Навыки

| Навык | Описание | Репозиторий |
|---|---|---|
| `gost-ed-mashiny` | Эксплуатационная документация на машины (РЭ по ГОСТ Р 2.610-2019, паспорт по ГОСТ Р 2.601-2019) и аудит по ТР ТС 010/2011. | [serjdrej/gost-ed-mashiny](https://github.com/serjdrej/gost-ed-mashiny) |
| `legal-ru` | Российское право для основателя-самоюриста: коммерческая тайна/NDA, 152-ФЗ (персональные данные), корпоративное право, досудебный порядок. | [serjdrej/legal-ru](https://github.com/serjdrej/legal-ru) |
| `patent-ru` | Патентный поиск и делопроизводство РФ: поиск аналогов через API Роспатента и составление/редактура заявочных документов по Требованиям № 107. | [serjdrej/patent-ru](https://github.com/serjdrej/patent-ru) |

## Adding a new skill

Этот маркетплейс не хранит содержимое навыков — каждый плагин живёт в своём
собственном репозитории, на который `marketplace.json` только ссылается.
Новый плагин — это любой самостоятельный репозиторий той же формы, что и три
перечисленных выше: корневой `SKILL.md` с валидным frontmatter, `LICENSE`,
`README.md`, опционально `.claude-plugin/plugin.json`, и `references/` для
содержательного материала.

Чтобы добавить такой репозиторий в этот маркетплейс, нужна ровно одна новая
запись в массиве `plugins` файла `.claude-plugin/marketplace.json` — с полями
`name`, `description` (взятым из `SKILL.md` этого репозитория), `author`,
`category` и `source` (`owner/name` репозитория и закреплённый SHA коммита).
Больше ничего в этом репозитории менять не нужно.

Если новый навык цитирует нормы (законы, ГОСТы, техрегламенты), прочитайте
[docs/norms-verification-convention.md](docs/norms-verification-convention.md)
перед тем, как писать его `references/norms-registry*.md` и скрипт
перепроверки — это общая для трёх существующих навыков конвенция оформления
реестра норм, выведенная из них, а не независимая от них схема.

## Для агентов, ведущих эти проекты

[docs/review-checklist.md](docs/review-checklist.md) — компактный чек-лист
для проверки любого плагина этой семьи (SKILL.md, README, гигиена
репозитория, синхронизация SHA в этом `marketplace.json`, статус
тестирования). Составлен по следам реальных находок в этой сессии, не из
абстрактных соображений — прочитать перед ревью любого из четырёх
репозиториев.
